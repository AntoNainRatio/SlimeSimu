# SlimeSimu

## Prerequesites

### CMake

```
sudo apt install cmake
```

### GTK

```
sudo apt-get install libgtk-3-dev
```

## Usage

To compile simply type in the repo:
```
make all
```

Then simply launch the executable in the repo:
```
./simu
```

You can pass the number of ships(ants) after the launch of the executable:
```
./simu <number of ships>
```

## Parameters

I invite you to play with the differents parameters presents in:
* `simu.c`
* `ship.h`
